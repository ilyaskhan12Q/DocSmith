# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   |  Current          |

## Reporting a Vulnerability

If you discover a security vulnerability in DocSmith, please report it responsibly:

1. **Do not** open a public GitHub issue
2. Email: **security@docsmith.dev**
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Response Timeline

- **Acknowledgement**: Within 48 hours
- **Initial assessment**: Within 5 business days
- **Fix release**: Within 30 days for critical issues

## Scope

Security concerns include:
- API key exposure or leakage
- Arbitrary code execution
- Data exfiltration from analyzed repositories
- Dependency vulnerabilities

## Disclosure Policy

We follow coordinated disclosure. We will:
1. Confirm the vulnerability
2. Develop and test a fix
3. Release the fix
4. Credit the reporter (unless they prefer anonymity)
5. Publish a security advisory
